# 品牌事实卡与内容模板

> 事实卡是所有 GEO 资产的单一事实源；内容模板让每块都能被单独摘走。

## 品牌事实卡（先建这个，再写任何内容）

llms.txt、JSON-LD、内容草稿全部从这张卡生成——口径统一从源头开始。存 `content/facts.md`，官网要有对应页面。

```markdown
## 实体
- 规范名：<全称>
- 别名/简称：<列全，含英文名、旧名、常见错写>
- 一句话定义：<X 是一款……，用于……>   ← 这句就是 AI 会摘走的那句
- 所属公司 / 成立时间 / 总部：
- 官网：

## 产品与能力
| 产品 | 定位 | 核心能力 | 适用对象 |

## 关键数字（每条必须带来源和核验日期）
| 事实 | 数值 | 来源 | 核验日期 | 证据等级 |

## 适用与不适用
- 适合：<3 条，具体到人群和场景>
- 不适合：<2 条>          ← 写清边界显著提升可信度与引用率

## 禁用表达
- 不要说：<绝对化/未经核实的说法>
- 改说：<可核实的版本>
```

**证据等级**：A 官方已证实 / B 第三方可佐证 / C 内部待授权 / D 需补证 / E 禁止使用。D 和 E 必须有处理动作，不许留着。

事实卡解决三个真实问题：① 全文实体拼写一致（实体混淆是过滤原因）；② AI 说错你时有唯一纠正依据（改卡→再生成所有资产）；③ 多人协作/多次生成口径不漂移。

## 定义型页面模板（实测影响力 0.1531，页面类型第一）

```
H1：什么是 <X>？（<一句话结论>）
  首段：直接回答不铺垫，60 字内给出定义。
H2：<X> 的定义与来源
H2：<X> 包含哪几部分         → 列表
H2：<X> 的 5 个关键数字       → 表格，每行带来源
H2：<X> 和 <Y> 有什么区别     → 对比表
H2：<X> 适合谁、不适合谁
H2：怎么开始用 <X>            → 编号步骤
H2：常见问题                  → 3-5 条
H2：参考来源                  → 真实可点开的链接
```

## 对比型页面模板（0.1524，性价比之王）

AI 回答"A 和 B 哪个好"时几乎必然找对比内容。规则：

- **同口径**：所有对象同一套维度，不能给自己加独有维度。
- 维度 6-10 个：定位、核心能力、价格、部署方式、集成、服务、适用规模、局限。
- **必须写自己的局限**——只夸自己的对比页可信度极低，容易被判营销内容。
- 每个结论后挂来源；结尾给决策树：`如果你是 X 且看重 Y → 选 Z`。

```markdown
| 维度 | 我方 | 竞品A | 竞品B |
|---|---|---|---|
| 定位 | | | |
| 价格起点 | | | |
> 数据核验日期：2026-XX-XX，来源见文末。
```

## 榜单/选型页

标题用用户原话：`2026 年 <品类> 怎么选？<N> 款主流方案对比`。结构同定义型，重点在覆盖度与中立感（收录竞品要真收录）。

## 证据页 vs 观点页（总纲）

**把内容写成"证据页"，不是"观点页"。** 每个要打的问题，页面至少具备：① 一句可直接摘走的定义；② 2-5 个带单位带出处的数字；③ 一个对比块（表格最佳）；④ 一个步骤块；⑤ 适用边界与不适用场景。判据与量化阈值见[四层模型与量化判据](11-four-layer-model.md)。
