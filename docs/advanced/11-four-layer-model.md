# 四层依赖模型与量化判据

> 六维评分回答"哪里差"，四层模型回答"先修哪个"。附全库最硬的量化阈值。

## 四层依赖模型（修复顺序判据）

```
访问 Access → 定向 Orientation → 理解 Understanding → 可引用 Quotability
```

| 层 | 回答的问题 | 典型检查 |
|----|-----------|---------|
| 访问 | 抓取器能拿到内容吗 | robots 封禁 / WAF-UA 差异封锁 / noindex（meta+响应头）/ SPA 空壳 |
| 定向 | 找得到、认得清每个 URL 吗 | sitemap（robots 里声明）/ canonical / llms.txt 链接有效性 / hreflang |
| 理解 | 机器读得懂这是什么实体吗 | JSON-LD / schema 与可见内容一致 / 目标市场原生语言 |
| 可引用 | 有值得引用的具体内容吗 | 长度、结构、抽取块、权威、对题（见下） |

**铁律：每层依赖上一层。** 访问层失败时，下游一切优化在引擎侧不可见——schema 再完美、内容再好，WAF 把 GPTBot 挡在门外等于不存在。**工单必须从失败的最上游层开始排**（框架出自 GeoReady《The GEO Readiness Manual》，与 geolook 采样观察一致）。

## 量化判据表（全部来自实测，非经验谈）

### 长度
| 判据 | 数字 |
|------|------|
| 被引 Top 四分位页均词数 | 1,943 词（Bottom 四分位仅 170，差 11.4 倍） |
| ≤100 词页影响力 | 0.0546 |
| 1001-3000 词 | 0.1258 |
| >3000 词 | 0.1457 |

**1000 词是门槛不是目标**——长不是目的，AI 需要足够材料才能切出可复用片段。

### 结构
| 判据 | Top 四分位 | Bottom 四分位 |
|------|-----------|--------------|
| 标题数 | 10.59 | 0.85 |
| 段落数 | 47.49 | 8.34 |
| 列表密度 li/(li+p) | 0.428 | 0.048 |

落地阈值：H1 唯一、H2 ≥6（目标 8-10）、段落 ≥25、列表密度 ≥0.35。

### 可抽取块（最大杠杆）
含数字 **+61.6%**、含定义 **+57.3%**、含对比 **+55.3%**、含 how-to **+41.2%** 影响力。页面类型均值：定义型 0.1531、对比型 0.1524、纯 reference 型仅 0.0529。

**反直觉警报：纯 Q&A 排版 −5.7%。** 把内容"排成问答的样子"没有用——有没有定义/数字/结构/对题性才有用。这修正了"FAQ 万能"的流行误解。

### 段落级可引用
检索的最小单元是段落不是页面：一段能直接回答问题的文字可以赢过竞品整页；页面再长、没有一段自包含可引，照样选不中。判据：按 H2 切段后，一段可引 = **≥60 词且含至少一种硬信息（数字/定义句/操作步骤）**。整页多节却零可引段 → 把核心小节改成"段首直接回答小节标题"的证据段。

### 对题性（最强单一预测因子）
`llm_relevance_score` 与影响力相关 **r=0.432**，高于语义相似度（0.356）与内容质量分（0.292）。标题/H1/H2 必须含目标问题的**实际用词**：
- 弱：`AI 正在改变世界`
- 强：`AI 搜索会优先引用什么内容？基于 23,745 条引用记录的结构化分析`

### 权威
被引来源域名权威度中位 DR 526-592（DR≥500 占 55-68%）。权威不自动等于高影响力，但决定**有没有资格进候选池**。

## 数据来源

以上数字出自开源数据集 GEOLab 的海外跨平台实验（602 prompts / 21,143 citations）与论文 arXiv:2604.25707《From Citation Selection to Citation Absorption》（标题已核验）；中文侧出自 arXiv:2607.15771（中文生成式搜索实证）。复算路径见 [中文信源实测榜](../guide/10-cn-source-ranking.md)。

## 三段漏斗提醒

```
提问 → ①是否触发联网检索 → ②哪些信源进引用列表 → ③哪些内容被吸收进答案
```
广度≠深度：Perplexity 平均每条引用 16.35 个来源、ChatGPT 仅 6.88；但 ChatGPT 单条引用影响力 0.2567，是 Perplexity 的 4.68 倍。**"被引用次数"和"真的被采纳"是两个指标，分开算。**
