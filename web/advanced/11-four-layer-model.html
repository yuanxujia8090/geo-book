四层依赖模型与量化判据

六维评分回答“哪里差“，四层模型回答“先修哪个“。附全库最硬的量化阈值。

四层依赖模型（修复顺序判据）

访问 Access → 定向 Orientation → 理解 Understanding → 可引用 Quotability
层回答的问题典型检查
访问抓取器能拿到内容吗robots 封禁 / WAF-UA 差异封锁 / noindex（meta+响应头）/ SPA 空壳
定向找得到、认得清每个 URL 吗sitemap（robots 里声明）/ canonical / llms.txt 链接有效性 / hreflang
理解机器读得懂这是什么实体吗JSON-LD / schema 与可见内容一致 / 目标市场原生语言
可引用有值得引用的具体内容吗长度、结构、抽取块、权威、对题（见下）

铁律：每层依赖上一层。 访问层失败时，下游一切优化在引擎侧不可见——schema 再完美、内容再好，WAF 把 GPTBot 挡在门外等于不存在。工单必须从失败的最上游层开始排（框架出自 GeoReady《The GEO Readiness Manual》，与 geolook 采样观察一致）。

可抽取块（最大杠杆）

含数字 +61.6%、含定义 +57.3%、含对比 +55.3%、含 how-to +41.2% 影响力。页面类型均值：定义型 0.1531、对比型 0.1524、纯 reference 型仅 0.0529。

反直觉警报：纯 Q&A 排版 −5.7%。 把内容“排成问答的样子“没有用——有没有定义/数字/结构/对题性才有用。这修正了“FAQ 万能“的流行误解。

段落级可引用

检索的最小单元是段落不是页面：一段能直接回答问题的文字可以赢过竞品整页；页面再长、没有一段自包含可引，照样选不中。判据：按 H2 切段后，一段可引 = ≥60 词且含至少一种硬信息（数字/定义句/操作步骤）。整页多节却零可引段 → 把核心小节改成“段首直接回答小节标题“的证据段。

规模化时别手工数：geolook 的做法是按上述判据全库自动扫描，把“有章节但零可引段“的页面直接点名成工单（README 诊断层，2026-11-06 核验其原文）；判定规则本身公开，可先用脚本粗实现（按 H2 切段+正则数词+关键词表匹配硬信息）。Auriti 的 geo-optimizer CLI 则是单页版自动扫描（见 projects/04）。

对题性（最强单一预测因子）

llm_relevance_score 与影响力相关 r=0.432，高于语义相似度（0.356）与内容质量分（0.292）。标题/H1/H2 必须含目标问题的实际用词：

  • 弱：AI 正在改变世界
  • 强：AI 搜索会优先引用什么内容？基于 23,745 条引用记录的结构化分析

权威

被引来源域名权威度中位 DR 526-592（DR≥500 占 55-68%）。权威不自动等于高影响力，但决定有没有资格进候选池。

数据来源

以上数字出自开源数据集 GEOLab 的海外跨平台实验（602 prompts / 21,143 citations）与论文 arXiv:2604.25707《From Citation Selection to Citation Absorption》（标题已核验）；中文侧出自 arXiv:2607.15771（中文生成式搜索实证）。复算路径见 中文信源实测榜。

三段漏斗提醒

提问 → ①是否触发联网检索 → ②哪些信源进引用列表 → ③哪些内容被吸收进答案

广度≠深度：Perplexity 平均每条引用 16.35 个来源、ChatGPT 仅 6.88；但 ChatGPT 单条引用影响力 0.2567，是 Perplexity 的 4.68 倍。“被引用次数“和“真的被采纳“是两个指标，分开算。
