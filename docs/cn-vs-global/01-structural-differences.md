# 国内外 GEO 结构性差异总览

> 中文 GEO 不是英文 GEO 的翻译版。信源、阵地、规则全不同，一套打法不能两地用。

## 一张表看懂差异

| 维度 | 海外（ChatGPT/Perplexity/Gemini） | 中文（豆包/元宝/千问/DeepSeek/文心） |
|------|-----------------------------------|--------------------------------------|
| 检索索引 | 自建索引 + Bing 依赖（ChatGPT） | 各家深度绑定自家内容生态（见下表） |
| 第一信源层 | Wikipedia、Reddit、权威媒体、.gov/.edu | 官方媒体（官媒）、百家号/公众号/抖音等自家系、榜单站 |
| 官网角色 | 事实源 + 一定比例直接引用 | 事实源；直接引用占比极低（实测 1.37%） |
| 第三方阵地 | Reddit、Quora、YouTube、科技媒体、目录站 | 知乎、CSDN、36氪、maigoo 榜单站、新浪/搜狐/网易号 |
| 权威信号 | E-E-A-T、域名权威、高质外链 | **官媒背书权重极高**、平台生态内权重、百科词条 |
| 中立战场 | Perplexity（对新内容友好） | DeepSeek（唯一无自家生态绑定，内容质量导向） |
| 数据授权 | Reddit/OpenAI 等大协议 | 平台间内容授权闭环（字节系→豆包、腾讯系→元宝） |
| 爬虫名录 | GPTBot、PerplexityBot、ClaudeBot | 各家爬虫公开度低，robots 控制粒度粗 |
| 度量生态 | Profound/Peec/Otterly 等成熟 SaaS | 工具少，手工采样 + 开源数据集（CN-GEO）为主 |

## 三个结构性差异（决定打法不同）

### 1. 生态割据 vs 索引竞争
海外引擎之间是"同一批公开网页，不同排序"；中文引擎是"各自住在自家内容池里"。豆包 App 的 iesdouyin 占 28.1%、元宝的 qq.com 占 20.5%、百度 AI 的 baidu.com 占 29-37.7%（CN-GEO 实测，高置信）。**在海外你优化"内容对搜索引擎的质量"；在中国你首先选择"进哪个内容池"——阵地选择先于内容优化。**

### 2. 官媒权重：中国特有的硬通货
中文引擎对官方媒体（人民网、新华网、央视及地方官媒）内容有系统性偏好——训练语料构成、内容审核机制、引用优先级三重叠加。海外没有对应物（.gov 有一定权重但不成体系）。这导致中文 GEO 出现特有打法：**通过正规渠道在官媒/权威媒体发布企业报道，作为品牌权威锚点**。具体见[官媒信源层](02-cn-official-media.md)。

### 3. 百科与问答平台的地位不同
海外 Wikipedia 是训练语料基石（占 LLM 训练数据约 5-15%，估算）；中文侧百度百科/搜狗百科 + 知乎问答承担类似角色，但门槛和玩法完全不同（中文百科创建审核严、需媒体佐证链）。Reddit 在海外是 GEO 主战场之一；中文对应物知乎的引用权重则明显低于字节系/腾讯系内容池。

## 打法速查：同一个目标，两地怎么做

| 目标 | 海外动作 | 中文动作 |
|------|---------|---------|
| 品牌被推荐 | Reddit 真实参与 + 权威媒体 review + Wikipedia 词条 | 官媒/行业媒体报道 + 百家号/公众号矩阵 + 百科词条 + maigoo 榜单 |
| 产品对比被引 | 中立对比页 + YouTube 评测 | 知乎对比回答 + 抖音图文 + 深度号测评 |
| 技术品牌 | GitHub + Hacker News + 技术博客 | CSDN/掘金/知乎专栏 + 公众号技术文 |
| 冷启动 | Perplexity 试验田 | DeepSeek 试验田（中立）+ 字节系铺量 |

两地都要做的公共层：可抓取（robots/渲染）、结构化数据、llms.txt、冻结问题集监测——技术地基全球通用，**上层阵地选择必须分开**。

## 常见误判

1. **把海外清单直接套中文**：在 Reddit 铺一年，豆包可能完全不认识你；反过来在知乎铺一年，ChatGPT 也可能不引你。信源池不互通（Web/App 重合度仅 24.5-31.4%，guide/10）。
2. **低估官媒**：出海团队常认为官媒"没流量所以没用"——但 GEO 要的不是流量是被引用，官媒内容在中文引擎里就是权威标签。
3. **高估官网**：中文官网直接引用率 1.37%；英文侧官网引用占比明显更高（Profound 口径约 20%+，medium 置信）。中文 GEO 预算大头应放第三方阵地，英文侧官网内容仍值得深耕。
