采样纪律与证据分级

采样不严谨，所有 GEO 数据都是噪音。这一篇是防自欺的操作规程。

证据分级（没有原文就不算真实采样）

等级含义
A人工/浏览器真实样本，有答案原文与来源链接
BAPI 可复现样本（注明是否联网）
C合成演示 / 推断
D待复核

纪律：没有原始答案、截图/导出、采样环境记录的，不许标成“真实采样“。 报告里 C/D 级样本必须显式标注，不许混进 A 级算指标。

采样环境四档（同纪律：不同环境不混算）

环境等级说明
sandbox 一次性沙箱A无历史无 Cookie 的干净浏览器，免登录引擎首选
incognito 无痕未登录A次选，随手可做
clean_profile 专用采样 ProfileA必须登录的引擎（豆包/Kimi/元宝/ChatGPT）用：只用于采样、从不搜自己品牌、关记忆与个性化
personal 个人日常账号自动降 D测的是“AI 对你的画像“（记忆/个性化污染），不能当可见性证据

核心原理：你要测的是“陌生人看到的 AI“，不是“AI 眼中的你“。个人账号里 AI 认识你，提及率虚高。

API ≠ 网页端

DeepSeek 官方 API 不联网——API 测的是模型参数化记忆里的品牌认知；网页端才有实时检索。两者分开记，绝不合并算提及率。 这也是为什么很多“API 采样工具“的数据与你在网页端看到的不一致。

Web ≠ App

CN-GEO 实测：千问 web 与 App 信源集合 Jaccard 相似度仅 24.5%（见中文信源榜）。每个平台+终端单独一行、单独口径，不允许用一个平台/终端的结论代表“AI 都这么说“。

指标至少四层

只看提及率会严重高估效果：

  1. 提及率：答案里有没有你
  2. 首位率 / Top3：你在推荐列表排第几
  3. 描述准确率：说到你的部分对不对
  4. 引用质量：召回（引用数）+ 准确（引用内容是否忠实）

归因链路：从被引用到值多少钱

用户问 AI → 答案引用你 → 点击引用链接 → 落地页 → 注册/咨询/下单
           （采样可测）    （referrer/UTM 可测）  （事件+来源快照可测）

三段各自能测、各自会漏，不能互相替代（GA4 配置细节见 GA4 篇）。

下界纪律：App 内打开常不带 referrer，测到的 AI 流量是下界——报告写“可归因的 AI 会话 ≥ N“，不写“AI 流量 = N“。AI 来源会话量小意图深，先看转化率不看会话数。公开内容不堆 UTM——带参 URL 被引用会稀释规范 URL 的引用份额。

爬虫是先行指标：服务器日志里 GPTBot/ClaudeBot 抓取量上涨通常先于引用量上涨，是免费的前置信号。

承诺边界（对客户/对自己）

  • 永远不能承诺“某平台一定会引用某页“——只能承诺提升可发现性、可验证性、可抽取性。
  • 归因默认写“观察相关“；要升格为因果，需要基线窗口+观察窗口+对照问题+竞品对照+外部事件记录五件套。
  • “疑似负面“标记是人工复核线索，不是判决书。

轻量周检节奏

每周只跑买家意图题（价格/推荐/比较/替代）20 条 × 每引擎，约半小时/引擎；全量题库留给月度正式采样。“没提到品牌“也照样记录——没提到正是最重要的数据。

零 API key 手动采样 SOP（无预算也能守纪律）

没有 API 预算时，手动采样不是“随便问问“，照 SOP 跑仍是 A 级证据（工程形态借 geolook 采样表/Chrome 助手与 geo-doctor 十题采样，README 核验 2026-11-06）：

  1. 出题：从冻结问题集按意图分组导出当周队列（买家意图优先，≤20 题/引擎）。
  2. 清场：无痕窗口或专用干净浏览器档（geolook 的 sandbox.sh 即“一次性干净浏览器“一键化；手动等价=无痕+未登录）。个人登录账号采的样按上文规则自动降级。
  3. 提问与回收：人工粘贴问题、等回答完整；手工版一题约 2 分钟/引擎。有 Chrome 采样助手则“填入→你按回车→一键抓回答+全部引用链接→回传本地表“，周检从 ~30 分钟压到 ~10 分钟（geolook 自报口径）。
  4. 落表：每题记录=回答原文全文＋引用域名清单＋采样时间＋环境档位，缺一不算 A 级。
  5. 重放：月度汇总后对争议样本按存原文重问一次，防偶发波动。
