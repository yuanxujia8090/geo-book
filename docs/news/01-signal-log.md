# 行业动态信号日志

> GEO 领域行为漂移快，静态知识库会过期。这一篇是"活页"：只记已核实的信号，低频维护。

## 收录规则（先立规矩，防止变成信息垃圾场）

1. **只收改变打法的信号**：引擎政策变更、新爬虫名录、索引机制调整、重量级数据集/论文发布。营销软文、"10个技巧"类清单不收。
2. **每条必带**：日期、来源链接、一句话事实、**"对打法的影响"**（没有影响的信号不记）、置信级（官方公告=高 / 一手实测=高 / 行业分析=medium / 传闻=低）。
3. **低频维护**：每月回顾一次即可；引擎大版本更新时加密到每周。过时信号标注 [已过时] 不删除——保留判断演变轨迹。
4. 本日志不承诺时效性——它是知识库的"勘误表+风向标"，不是新闻订阅。
